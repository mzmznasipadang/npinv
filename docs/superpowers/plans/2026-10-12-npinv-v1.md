# NPInv v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build and deploy the Naspad Studio invoice dashboard: create invoices, save them as branded A4 PDFs, track outstanding, overdue and paid totals, on naspad-server over Tailscale.

**Architecture:** One Next.js 16 App Router application in one container. Pure logic (`money`, `rules`) and the SQLite repository (`db`, `repo`, `schemas`) have no Next imports and are tested with `node --test`. Server Actions validate with zod and call the repository; pages read through the repository after `await connection()`. The invoice PDF is a print-ready route printed by the browser.

**Tech Stack:** Next.js 16.4.0, React 19.3.0, TypeScript, Tailwind CSS 4, shadcn/ui 4.21.4 (Radix base, `nova` preset), next-themes 0.4.6, zod 4.6.6, SQLite via `node:sqlite`, Node 24.21.0 LTS in Docker, Docker Compose, Tailscale Serve.

**Spec:** `docs/superpowers/specs/2026-10-12-npinv-design.md`

## Global Constraints

- Brand colours, exact: Naspad Navy `#272660`, Sky Blue `#49BCE9`, Pure White `#FFFFFF`, Black `#000000`.
- Sky Blue never carries white text and is never text on white. Every text/background pair reaches at least 4.5:1.
- Typeface: Montserrat, weights 300, 500, 600, 700. Fallback: Calibri, Arial, sans-serif.
- Logo: only the files in `public/brand/`. Never redrawn, recoloured, stretched, or given shadows or other effects.
- Money: integers in the smallest unit (whole rupiah, cents). No floating-point arithmetic on amounts.
- Currencies: `IDR` and `USD` only. Amounts in different currencies are never added together.
- Time zone for "today" and "this month": `Asia/Jakarta`.
- Database: SQLite through `node:sqlite`, plain SQL, no ORM.
- Every Server Action validates its input before touching the database. Arguments from the client are untrusted, including ids.
- No login, no secrets, no `.env` file in v1.
- Container port is published as `127.0.0.1:3003` only. Exposure is `tailscale serve` on HTTPS port 8445 only. Nothing is ever added under the `:443` listener.
- No new packages on the server host. No existing server service is modified.
- Base image: `node:24.21.0-slim`.
- Only committed code is deployed.
- Git identity is repo-local (already set). Every commit message ends with the trailer `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- Next.js 16.4 differs from older versions. Before writing framework code not shown in this plan, read the matching guide in `node_modules/next/dist/docs/`.

## Facts established before planning

These were checked on 2026-10-12 in a throwaway copy, not assumed.

- `create-next-app@16.4.0` rejects the folder name `NPInv` (capitals), so the app is scaffolded in a temporary folder named `npinv` and moved in.
- The scaffold enables `cacheComponents` and `partialPrefetching`. A page that reads the database must `await connection()` and sit under a Suspense boundary (`loading.tsx`), or export `instant = false`. The old `export const dynamic` option no longer exists.
- `node:sqlite` builds and runs under Turbopack. It needs `@types/node@24`.
- `node --test` runs `.ts` files directly. Modules it loads must import each other with explicit `.ts` extensions and use `import type` for types. This needs `"type": "module"` in `package.json` and `allowImportingTsExtensions` in `tsconfig.json`.
- A streamed route answers HTTP 200 even when it renders the not-found page, so not-found is checked by page content, not status code.
- The shadcn-generated `src/hooks/use-mobile.ts` fails the scaffold's lint rule, so generated UI code is excluded from linting.
- The guideline PDFs hold the wordmark as vectors but the icon only as a 1708×1220 image with transparency. The supergraphic on the Billing Statement page is that same image placed at 34.6% from the left, 27.9% from the top, 220.7% of the page width, at about 15% opacity (measured by fitting, 99.1% agreement).
- Multi-page printing works in Chromium with a zero page margin, fixed footer bar and supergraphic, and an outer table whose header and footer rows reserve the top and bottom margins on every page.
- The user's default browser is Arc (Chromium). There is no Google Chrome; print checks use Playwright's Chromium from a folder outside the repo.
- `git ls-remote origin` succeeds with the credentials already in the macOS keychain.
- Server: x86_64, about 2 GB RAM free plus 3.7 GB swap, ports 3000–3002 and HTTPS 443/8443/8444 in use, uid 1000 is `naspad-server`, backups run from `/etc/cron.d`, no `sqlite3` on the host.

```ts
export type Currency = "IDR" | "USD";
export const CURRENCIES: readonly Currency[] = ["IDR", "USD"];

const DECIMALS: Record<Currency, number> = { IDR: 0, USD: 2 };

export type Line = { qty: number; unitPrice: number };
export type Totals = { subtotal: number; taxAmount: number; total: number };

export function lineTotal(line: Line): number {
  return line.qty * line.unitPrice;
}

/**
 * Totals in the smallest unit. Tax is rounded half up.
 * Throws RangeError when the total is too large to store exactly.
 */
export function invoiceTotals(lines: readonly Line[], taxRateBp: number): Totals {
  let subtotal = 0n;
  for (const line of lines) subtotal += BigInt(line.qty) * BigInt(line.unitPrice);
  const taxAmount = (subtotal * BigInt(taxRateBp) + 5000n) / 10000n;
  const total = subtotal + taxAmount;
  if (total > BigInt(Number.MAX_SAFE_INTEGER)) throw new RangeError("Amount is too large");
  return { subtotal: Number(subtotal), taxAmount: Number(taxAmount), total: Number(total) };
}

export function formatMoney(minor: number, currency: Currency): string {
  if (currency === "IDR") return `Rp ${new Intl.NumberFormat("id-ID").format(minor)}`;
  const dollars = new Intl.NumberFormat("en-US", { minimumFractionDigits: 2, maximumFractionDigits: 2 });
  return `$${dollars.format(minor / 100)}`;
}

/** Parses a plain decimal such as "1500000" or "19.99" into the smallest unit. Null when invalid. */
export function parseAmount(input: string, currency: Currency): number | null {
  const match = /^(\d{1,13})(?:\.(\d{1,2}))?$/.exec(input.trim());
  if (!match) return null;
  const whole = Number(match[1]);
  const fraction = match[2] ?? "";
  if (DECIMALS[currency] === 0) return /^0*$/.test(fraction) ? whole : null;
  return whole * 100 + Number(fraction.padEnd(2, "0"));
}

/** The inverse of parseAmount, for filling number inputs. */
export function amountToInput(minor: number, currency: Currency): string {
  if (DECIMALS[currency] === 0) return String(minor);
  return `${Math.floor(minor / 100)}.${String(minor % 100).padStart(2, "0")}`;
}

/** "11" or "11.5" to basis points. Null when invalid or above 100%. */
export function parsePercent(input: string): number | null {
  const match = /^(\d{1,3})(?:\.(\d{1,2}))?$/.exec(input.trim());
  if (!match) return null;
  const bp = Number(match[1]) * 100 + Number((match[2] ?? "").padEnd(2, "0"));
  return bp <= 10000 ? bp : null;
}

export function percentToInput(bp: number): string {
  return String(bp / 100);
}
```

```ts
export type Status = "draft" | "sent" | "paid";
export type DisplayStatus = Status | "overdue";

const TIME_ZONE = "Asia/Jakarta";

/** Today's date as YYYY-MM-DD in the business time zone. */
export function today(now: Date = new Date()): string {
  return new Intl.DateTimeFormat("en-CA", {
    timeZone: TIME_ZONE,
    year: "numeric",
    month: "2-digit",
    day: "2-digit",
  }).format(now);
}

export function addDays(date: string, days: number): string {
  const d = new Date(`${date}T00:00:00Z`);
  d.setUTCDate(d.getUTCDate() + days);
  return d.toISOString().slice(0, 10);
}

export function isValidDate(s: string): boolean {
  if (!/^\d{4}-\d{2}-\d{2}$/.test(s)) return false;
  const d = new Date(`${s}T00:00:00Z`);
  return !Number.isNaN(d.getTime()) && d.toISOString().slice(0, 10) === s;
}

/** "2026-10-12" to "12 October 2026". */
export function formatDate(date: string): string {
  return new Intl.DateTimeFormat("en-GB", {
    day: "numeric",
    month: "long",
    year: "numeric",
    timeZone: "UTC",
  }).format(new Date(`${date}T00:00:00Z`));
}

/** Overdue means sent and due before today. Due today is not overdue. */
export function displayStatus(status: Status, dueDate: string, todayDate: string): DisplayStatus {
  return status === "sent" && dueDate < todayDate ? "overdue" : status;
}

export function formatNumber(prefix: string, year: string, seq: number): string {
  return `${prefix}-${year}-${String(seq).padStart(3, "0")}`;
}

/** One above the highest sequence already used for this prefix and year. */
export function nextSequence(numbers: readonly string[], prefix: string, year: string): number {
  const head = `${prefix}-${year}-`;
  let max = 0;
  for (const n of numbers) {
    if (!n.startsWith(head)) continue;
```

```ts
function open(): DatabaseSync {
  const path = process.env.DATABASE_PATH ?? "data/npinv.db";
  if (path !== ":memory:") mkdirSync(dirname(path), { recursive: true });
  const db = new DatabaseSync(path);
  db.exec("PRAGMA busy_timeout = 5000; PRAGMA journal_mode = WAL; PRAGMA foreign_keys = ON;");
  // The version check and the schema run in one write transaction, so two
  // processes starting together cannot both create the tables.
  db.exec("BEGIN IMMEDIATE");
  try {
    const { user_version: version } = db.prepare("PRAGMA user_version").get() as { user_version: number };
    if (version < 1) db.exec(`${SCHEMA} PRAGMA user_version = 1;`);
    db.exec("COMMIT");
  } catch (error) {
    db.exec("ROLLBACK");
    throw error;
  }
  return db;
}

// One connection per process. It is opened on first use, not on import, and
// kept on globalThis so development hot reloads reuse it.
const holder = globalThis as unknown as { __npinvDb?: DatabaseSync };

export function getDb(): DatabaseSync {
  return (holder.__npinvDb ??= open());
}

export function transaction<T>(fn: () => T): T {
  const db = getDb();
  db.exec("BEGIN IMMEDIATE");
  try {
    const result = fn();
    db.exec("COMMIT");
    return result;
  } catch (error) {
    db.exec("ROLLBACK");
    throw error;
  }
}
```

```ts
    args.push(todayDate);
  } else if (filter.status === "overdue") {
    where.push("status = 'sent' AND due_date < ?");
    args.push(todayDate);
  }
  const q = filter.q?.trim();
  if (q) {
    const like = `%${q.replace(/[\\%_]/g, "\\$&")}%`;
    where.push(
      "(number LIKE ? ESCAPE '\\' OR bill_to_name LIKE ? ESCAPE '\\' OR bill_to_company LIKE ? ESCAPE '\\')",
    );
    args.push(like, like, like);
  }
  const rows = many<Omit<InvoiceRow, "display">>(
    `SELECT ${ROW_COLS} FROM invoices ${where.length ? `WHERE ${where.join(" AND ")}` : ""}
     ORDER BY issue_date DESC, id DESC LIMIT ?`,
    ...args,
    limit,
  );
  return rows.map((row) => ({ ...row, display: displayStatus(row.status, row.dueDate, todayDate) }));
}

export function getInvoice(id: number): Invoice | null {
  const invoice = one<Omit<Invoice, "items">>(`SELECT ${INVOICE_COLS} FROM invoices WHERE id = ?`, id);
  if (!invoice) return null;
  const items = many<ItemInput>(
    "SELECT description, qty, unit_price AS unitPrice, notes FROM invoice_items WHERE invoice_id = ? ORDER BY position",
    id,
  );
  return { ...invoice, items };
}

/** Creates (id null) or updates an invoice. Throws RangeError for an unstorable total, NotFoundError for a missing id. */
export function saveInvoice(id: number | null, input: InvoiceInput): number {
  const totals = invoiceTotals(input.items, input.taxRateBp);
  return transaction(() => {
    // The client may have been deleted while the form was open.
    const clientId =
      input.clientId !== null && one("SELECT 1 AS found FROM clients WHERE id = ?", input.clientId)
        ? input.clientId
        : null;
    const fields: Arg[] = [
      clientId, input.billToName, input.billToCompany, input.billToAddress, input.issueDate, input.dueDate,
      input.currency, input.taxRateBp, input.notes, totals.subtotal, totals.taxAmount, totals.total,
    ];
    let invoiceId: number;
    if (id === null) {
      invoiceId = run(
        `INSERT INTO invoices (client_id, bill_to_name, bill_to_company, bill_to_address, issue_date, due_date,
           currency, tax_rate_bp, notes, subtotal, tax_amount, total) VALUES (?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?)`,
        ...fields,
      ).id;
    } else {
      const { changes } = run(
        `UPDATE invoices SET client_id = ?, bill_to_name = ?, bill_to_company = ?, bill_to_address = ?,
           issue_date = ?, due_date = ?, currency = ?, tax_rate_bp = ?, notes = ?, subtotal = ?, tax_amount = ?,
           total = ?, updated_at = datetime('now') WHERE id = ?`,
        ...fields,
        id,
      );
      if (changes === 0) throw new NotFoundError(`Invoice ${id} does not exist`);
      run("DELETE FROM invoice_items WHERE invoice_id = ?", id);
      invoiceId = id;
    }
    input.items.forEach((item, position) => {
      run(
        "INSERT INTO invoice_items (invoice_id, position, description, qty, unit_price, notes) VALUES (?, ?, ?, ?, ?, ?)",
        invoiceId, position, item.description, item.qty, item.unitPrice, item.notes,
      );
    });
    return invoiceId;
  });
}

/** The next number in sequence for the invoice's issue year. Null when the invoice does not exist. */
export function suggestNumber(id: number): string | null {
  const invoice = one<{ issueDate: string }>("SELECT issue_date AS issueDate FROM invoices WHERE id = ?", id);
  if (!invoice) return null;
  const { invoicePrefix } = getSettings();
  const year = invoice.issueDate.slice(0, 4);
  // The prefix is letters and digits only (see schemas.ts), so it needs no LIKE escaping.
  const numbers = many<{ number: string }>(
    "SELECT number FROM invoices WHERE number LIKE ?",
    `${invoicePrefix}-${year}-%`,
  ).map((row) => row.number);
  return formatNumber(invoicePrefix, year, nextSequence(numbers, invoicePrefix, year));
}

type StatusRow = { status: Status; number: string | null };

function statusOf(id: number): StatusRow | undefined {
  return one<StatusRow>("SELECT status, number FROM invoices WHERE id = ?", id);
}

/** Marks a draft sent. Assigns `number` unless the invoice already has one; a number never changes. */
export function markSent(id: number, number: string): Result {
  return transaction((): Result => {
    const invoice = statusOf(id);
    if (!invoice) return { ok: false, error: "This invoice no longer exists." };
    if (invoice.status !== "draft") return { ok: false, error: "Only a draft can be marked sent." };
    const final = invoice.number ?? number;
    if (one("SELECT 1 AS found FROM invoices WHERE number = ? AND id <> ?", final, id)) {
      return { ok: false, error: `Number ${final} is already used by another invoice.` };
    }
    run("UPDATE invoices SET status = 'sent', number = ?, updated_at = datetime('now') WHERE id = ?", final, id);
    return { ok: true };
  });
}

export function markPaid(id: number, paidAt: string): Result {
  return transaction((): Result => {
    const invoice = statusOf(id);
    if (!invoice) return { ok: false, error: "This invoice no longer exists." };
    if (invoice.status !== "sent") return { ok: false, error: "Only a sent invoice can be marked paid." };
    run("UPDATE invoices SET status = 'paid', paid_at = ?, updated_at = datetime('now') WHERE id = ?", paidAt, id);
    return { ok: true };
  });
}

/** One step back: paid to sent, or sent to draft. The number is kept. */
export function undoStatus(id: number): Result {
  return transaction((): Result => {
    const invoice = statusOf(id);
    if (!invoice) return { ok: false, error: "This invoice no longer exists." };
    if (invoice.status === "draft") return { ok: false, error: "A draft has nothing to undo." };
    const previous: Status = invoice.status === "paid" ? "sent" : "draft";
    run(
      "UPDATE invoices SET status = ?, paid_at = NULL, updated_at = datetime('now') WHERE id = ?",
      previous,
      id,
    );
    return { ok: true };
  });
}

/** A new unnumbered draft with the same content, issued today. Null when the source does not exist. */
export function duplicateInvoice(id: number, todayDate: string): number | null {
  const source = getInvoice(id);

    items: source.items,
  });
}

}

export function dashboard(todayDate: string): { summaries: CurrencySummary[]; latest: InvoiceRow[] } {
  const summaries = many<CurrencySummary>(
    `SELECT currency,
       COALESCE(SUM(CASE WHEN status = 'sent' THEN total END), 0) AS outstanding,
       COALESCE(SUM(CASE WHEN status = 'sent' AND due_date < ? THEN total END), 0) AS overdue,
       COALESCE(SUM(CASE WHEN status = 'paid' AND substr(paid_at, 1, 7) = ? THEN total END), 0) AS paidThisMonth
     FROM invoices GROUP BY currency ORDER BY currency`,
    todayDate,
    todayDate.slice(0, 7),
  );
  return { summaries, latest: listInvoices({}, todayDate, 10) };
}
```

```ts
const DAYS_MESSAGE = "A number of days from 0 to 365";

const text = (max: number) => z.string().trim().max(max, `At most ${max} characters`);
const required = (max: number, message: string) => text(max).min(1, message);
const date = z.string().refine(isValidDate, "Enter a valid date");
const email = z.union([z.literal(""), z.email("Enter a valid email address")]);
const currency = z.enum(["IDR", "USD"], "Choose IDR or USD");

/** A percentage such as "11" or "11.5", stored as basis points. */
const percent = z
  .string()
  .refine((s) => parsePercent(s) !== null, RATE_MESSAGE)
  .transform((s) => parsePercent(s) ?? 0);

/** An amount in the given currency, stored in its smallest unit. */
const amount = (cur: Currency) =>
  z
    .string()
    .refine(
      (s) => parseAmount(s, cur) !== null,
      cur === "IDR" ? "Whole rupiah, digits only" : "An amount such as 150 or 150.50",
    )
    .transform((s) => parseAmount(s, cur) ?? 0);

/** The first message for each field, keyed by its dotted path. */
function collect(error: z.ZodError): FieldErrors {
  const errors: FieldErrors = {};
  for (const issue of error.issues) errors[issue.path.join(".") || "form"] ??= issue.message;
  return errors;
}

export function parseInvoiceForm(values: unknown): Parsed<InvoiceInput> {
  // Three rules depend on another field: the price format on the currency, the
  // tax rate on the switch, and the due date on the issue date. The schema is
  // built per submission so every field still reports its own error in one pass.
  const raw = typeof values === "object" && values !== null ? (values as Record<string, unknown>) : {};
  const cur: Currency = raw.currency === "USD" ? "USD" : "IDR";
  const issueDate = typeof raw.issueDate === "string" && isValidDate(raw.issueDate) ? raw.issueDate : null;

  const schema = z.object({
    clientId: z
      .string()
      .regex(/^\d{0,15}$/, "Unknown client")
      .transform((s) => (s === "" ? null : Number(s))),
    billToName: required(200, "Enter the client's name"),
    billToCompany: text(200),
    billToAddress: text(500),
    issueDate: date,
    dueDate: date.refine(
      (d) => issueDate === null || d >= issueDate,
      "The due date cannot be before the issue date",
    ),
    currency,
    taxRate: raw.taxEnabled === true ? percent : z.unknown().transform(() => 0),
    notes: text(2000),
    items: z
      .array(
        z.object({
          description: required(300, "Describe the item"),
          qty: z
            .string()
            .trim()
            .regex(/^[1-9]\d{0,5}$/, "Whole number, at least 1")
            .transform(Number),
          unitPrice: amount(cur),
          notes: text(200),
        }),
      )
      .min(1, "Add at least one item")
      .max(200, "At most 200 items"),
  });

  const result = schema.safeParse(values);
  if (!result.success) return { ok: false, errors: collect(result.error) };
  const { taxRate, ...rest } = result.data;
  return { ok: true, data: { ...rest, taxRateBp: taxRate } };
}
```

- [ ] **Step 1: Build the logo files from the guideline**

The guideline holds the wordmark as vectors and the icon as an image, so the lockups are SVGs that embed the icon image beside the vector wordmark, using the positions on the Logo Grid page. The tool is throwaway and stays outside the repo.

Save the following as `$WORK/make_brand.py` (the commands below create `$WORK`):

```python
"""Build Naspad Studio logo files from the brand guideline PDF.

Usage: python -I make_brand.py "<guideline dir>/13_Logo Grid.pdf" <out dir>
"""
import base64, io, sys
import pymupdf
from PIL import Image

src, out = sys.argv[1], sys.argv[2]
doc = pymupdf.open(src)
page = doc[0]

# Icon: the only image on the page.
(info,) = page.get_image_info(xrefs=True)
ix0, iy0, ix1, iy1 = info["bbox"]
img = next(i for i in page.get_images(full=True) if i[0] == info["xref"])
pix = pymupdf.Pixmap(pymupdf.Pixmap(doc, img[0]), pymupdf.Pixmap(doc, img[1]))
pix.save(f"{out}/icon.png")
icon = Image.open(f"{out}/icon.png")
ax0, ay0, ax1, ay1 = icon.getchannel("A").getbbox()
sx, sy = (ix1 - ix0) / icon.width, (iy1 - iy0) / icon.height
visible = (ix0 + ax0 * sx, iy0 + ay0 * sy, ix0 + ax1 * sx, iy0 + ay1 * sy)

# Wordmark: the one large Navy vector drawing to the right of the icon.
def is_navy(c):
    return c and abs(c[0] - 0.153) < 0.02 and abs(c[1] - 0.149) < 0.02 and abs(c[2] - 0.376) < 0.02
word = max((d for d in page.get_drawings() if is_navy(d.get("fill")) and d["rect"].x0 > ix1),
           key=lambda d: d["rect"].get_area())
wr = word["rect"]

def f(v):
    return f"{v:.2f}".rstrip("0").rstrip(".")
parts, cur = [], None
for it in word["items"]:
    kind = it[0]
    if kind == "re":
        r = it[1]
        parts.append(f"M{f(r.x0)} {f(r.y0)}H{f(r.x1)}V{f(r.y1)}H{f(r.x0)}Z"); cur = None
        continue
    if kind == "qu":
        q = it[1]
        parts.append(f"M{f(q.ul.x)} {f(q.ul.y)}L{f(q.ur.x)} {f(q.ur.y)}L{f(q.lr.x)} {f(q.lr.y)}L{f(q.ll.x)} {f(q.ll.y)}Z"); cur = None
        continue
    start, end = it[1], it[-1]
    if cur is None or abs(start.x - cur.x) > 0.01 or abs(start.y - cur.y) > 0.01:
        parts.append(f"M{f(start.x)} {f(start.y)}")
    if kind == "l":
        parts.append(f"L{f(end.x)} {f(end.y)}")
    elif kind == "c":
        parts.append(f"C{f(it[2].x)} {f(it[2].y)} {f(it[3].x)} {f(it[3].y)} {f(end.x)} {f(end.y)}")
    cur = end
d_attr = "".join(parts)
rule = "evenodd" if word.get("even_odd") else "nonzero"

# Lockup box: what is visible of the icon, plus the wordmark.
x0, y0 = min(visible[0], wr.x0), min(visible[1], wr.y0)
x1, y1 = max(visible[2], wr.x1), max(visible[3], wr.y1)

small = icon.resize((768, round(768 * icon.height / icon.width)), Image.LANCZOS)
buf = io.BytesIO(); small.save(buf, "PNG", optimize=True)
b64 = base64.b64encode(buf.getvalue()).decode()

for name, colour in (("logo-navy", "#272660"), ("logo-white", "#FFFFFF")):
    svg = (
        f'<svg xmlns="http://www.w3.org/2000/svg" viewBox="{f(x0)} {f(y0)} {f(x1 - x0)} {f(y1 - y0)}" role="img" aria-label="Naspad Studio">'
        f'<image href="data:image/png;base64,{b64}" x="{f(ix0)}" y="{f(iy0)}" width="{f(ix1 - ix0)}" height="{f(iy1 - iy0)}"/>'
        f'<path fill="{colour}" fill-rule="{rule}" d="{d_attr}"/></svg>'
    )
    open(f"{out}/{name}.svg", "w").write(svg)
print("viewBox", f(x0), f(y0), f(x1 - x0), f(y1 - y0), "aspect", round((x1 - x0) / (y1 - y0), 4))
```

- [ ] **Step 1: Create the Server Actions for settings and clients**

Create `src/lib/actions.ts`:

```ts
"use server";

import { revalidatePath } from "next/cache";
import * as repo from "./repo";
import { parseClientForm, parseSettingsForm } from "./schemas";
import type { ClientFormValues, FormState, SettingsFormValues } from "./schemas";

// Arguments arrive from the browser, so ids are checked like any other input.
function isId(value: unknown): value is number {
  return typeof value === "number" && Number.isSafeInteger(value) && value > 0;
}

function refresh(): void {
  revalidatePath("/", "layout");
}

export async function saveSettingsAction(values: SettingsFormValues): Promise<FormState> {
  const parsed = parseSettingsForm(values);
  if (!parsed.ok) return { errors: parsed.errors };
  repo.updateSettings(parsed.data);
  refresh();
  return { ok: true };
}

export async function saveClientAction(id: number | null, values: ClientFormValues): Promise<FormState> {
  if (id !== null && !isId(id)) return { message: "This client no longer exists." };
  const parsed = parseClientForm(values);
  if (!parsed.ok) return { errors: parsed.errors };
  if (id === null) repo.createClient(parsed.data);
  else if (!repo.updateClient(id, parsed.data)) return { message: "This client no longer exists." };
  refresh();
  return { ok: true };
}

export async function deleteClientAction(id: number): Promise<FormState> {
  if (!isId(id) || !repo.deleteClient(id)) return { message: "This client no longer exists." };
  refresh();
  return { ok: true };
}
```

```ts
import type { FormEvent } from "react";
import { toast } from "sonner";
import type { FieldErrors, FormState } from "@/lib/schemas";

/** Controlled form values, submitted through a Server Action that returns field errors. */
export function useServerForm<V extends object>(initial: V, submit: (values: V) => Promise<FormState>) {
  const [values, setValues] = useState<V>(initial);
  const [state, setState] = useState<FormState>({});
  const [pending, startTransition] = useTransition();

  function set<K extends keyof V>(key: K, value: V[K]) {
    setValues((current) => ({ ...current, [key]: value }));
  }

  function reset(next: V) {
    setValues(next);
    setState({});
  }

  function onSubmit(event: FormEvent) {
    event.preventDefault();
    startTransition(async () => {
      const result = await submit(values);
      if (!result) return; // the action redirected
      setState(result);
      if (result.message) toast.error(result.message);
    });
  }

  const errors: FieldErrors = state.errors ?? {};
  return { values, setValues, set, reset, errors, pending, onSubmit };
}

/** Runs a one-off Server Action with a pending flag, and a toast when it fails. */
export function useAction() {
  const [pending, startTransition] = useTransition();

  function run(action: () => Promise<FormState>, onOk?: () => void) {
    startTransition(async () => {
      const result = await action();
      if (!result) return; // the action redirected
      if (result.ok) onOk?.();
      else toast.error(result.message ?? Object.values(result.errors ?? {})[0] ?? "Something went wrong.");
    });
  }

  return { pending, run };
}
```

```ts
"use server";

import { revalidatePath } from "next/cache";
import { redirect } from "next/navigation";
import * as repo from "./repo";
import { isValidDate, today } from "./rules";
import { parseClientForm, parseInvoiceForm, parseInvoiceNumber, parseSettingsForm } from "./schemas";
import type { ClientFormValues, FormState, InvoiceFormValues, SettingsFormValues } from "./schemas";

const GONE = "This invoice no longer exists.";

// Arguments arrive from the browser, so ids are checked like any other input.
function isId(value: unknown): value is number {
  return typeof value === "number" && Number.isSafeInteger(value) && value > 0;
}

function refresh(): void {
  revalidatePath("/", "layout");
}

export async function saveSettingsAction(values: SettingsFormValues): Promise<FormState> {
  const parsed = parseSettingsForm(values);
  if (!parsed.ok) return { errors: parsed.errors };
  repo.updateSettings(parsed.data);
  refresh();
  return { ok: true };
}

export async function saveClientAction(id: number | null, values: ClientFormValues): Promise<FormState> {
  if (id !== null && !isId(id)) return { message: "This client no longer exists." };
  const parsed = parseClientForm(values);
  if (!parsed.ok) return { errors: parsed.errors };
  if (id === null) repo.createClient(parsed.data);
  else if (!repo.updateClient(id, parsed.data)) return { message: "This client no longer exists." };
  refresh();
  return { ok: true };
}

export async function deleteClientAction(id: number): Promise<FormState> {
  if (!isId(id) || !repo.deleteClient(id)) return { message: "This client no longer exists." };
  refresh();
  return { ok: true };
}

export async function saveInvoiceAction(id: number | null, values: InvoiceFormValues): Promise<FormState> {
  if (id !== null && !isId(id)) return { message: GONE };
  const parsed = parseInvoiceForm(values);
  if (!parsed.ok) return { errors: parsed.errors };
  let savedId: number;
  try {
    savedId = repo.saveInvoice(id, parsed.data);
  } catch (error) {
    if (error instanceof RangeError) return { message: "The invoice total is too large to store." };
    if (error instanceof repo.NotFoundError) return { message: GONE };
    throw error;
  }
  refresh();
  if (id === null) redirect(`/invoices/${savedId}`);
  return { ok: true };
}

export async function markSentAction(id: number, number: string): Promise<FormState> {
  if (!isId(id)) return { message: GONE };
  const parsed = parseInvoiceNumber(number);
  if (!parsed.ok) return { errors: parsed.errors };
  const result = repo.markSent(id, parsed.data);
  if (!result.ok) return { message: result.error };
  refresh();
  return { ok: true };
}

export async function markPaidAction(id: number, paidAt: string): Promise<FormState> {
  if (!isId(id)) return { message: GONE };
  if (typeof paidAt !== "string" || !isValidDate(paidAt)) return { errors: { paidAt: "Enter a valid date" } };
  const result = repo.markPaid(id, paidAt);
  if (!result.ok) return { message: result.error };
  refresh();
  return { ok: true };
}

export async function undoStatusAction(id: number): Promise<FormState> {
  if (!isId(id)) return { message: GONE };
  const result = repo.undoStatus(id);
  if (!result.ok) return { message: result.error };
  refresh();
  return { ok: true };
}

export async function duplicateInvoiceAction(id: number): Promise<FormState> {
  if (!isId(id)) return { message: GONE };
  const copyId = repo.duplicateInvoice(id, today());
  if (copyId === null) return { message: GONE };
  refresh();
  redirect(`/invoices/${copyId}`);
}

export async function deleteInvoiceAction(id: number): Promise<FormState> {
  if (!isId(id) || !repo.deleteInvoice(id)) {
    return { message: "Only a draft that was never numbered can be deleted." };
  }
  refresh();
  redirect("/invoices");
}
```

```tsx
"use client";

import { useEffect } from "react";
import Link from "next/link";

type PrintToolbarProps = { auto: boolean; backHref: string; title: string };

/** Screen-only controls. With `auto`, opens the print dialog once fonts and images are ready. */
export function PrintToolbar({ auto, backHref, title }: PrintToolbarProps) {
  useEffect(() => {
    // The browser offers the document title as the PDF file name.
    document.title = title;
    if (!auto) return;
    let cancelled = false;
    const images = Array.from(document.images, (image) => image.decode().catch(() => undefined));
    Promise.all([document.fonts.ready, ...images]).then(() => {
      if (!cancelled) window.print();
    });
    return () => {
      cancelled = true;
    };
  }, [auto, title]);

  return (
    <div className="toolbar">
      <Link href={backHref}>Back to invoice</Link>
      <button type="button" onClick={() => window.print()}>
        Print / Save as PDF
      </button>
    </div>
  );
}
```

- [ ] **Step 3: Create the deploy script**

Create `deploy/deploy.sh`:

```bash
#!/usr/bin/env bash
# Deploys the last commit to naspad-server. Run on the Mac, from anywhere in the repo.
# The Mac must be on the personal tailnet. Uncommitted changes are not deployed.
set -euo pipefail

HOST="${NPINV_HOST:-root@<server-tailscale-ip>}"
cd "$(git rev-parse --show-toplevel)"

if [ -n "$(git status --porcelain)" ]; then
  echo "Note: uncommitted changes are NOT deployed; deploying $(git rev-parse --short HEAD)." >&2
fi

echo "==> Sending $(git rev-parse --short HEAD) to $HOST"
ssh -o ConnectTimeout=10 "$HOST" '
  set -e
  rm -rf /srv/npinv/src
  mkdir -p /srv/npinv/src /srv/npinv/data /srv/npinv/backups
  chown 1000:1000 /srv/npinv/data /srv/npinv/backups
'
git archive HEAD | ssh "$HOST" 'tar -x -C /srv/npinv/src'

echo "==> Building and starting"
ssh "$HOST" '
  set -e
  cp /srv/npinv/src/deploy/compose.yaml /srv/npinv/compose.yaml
  cd /srv/npinv
  docker compose up -d --build
  docker image prune -f >/dev/null
'

echo "==> Waiting for the app"
ssh "$HOST" '
  for i in $(seq 1 30); do
    if curl -fsS -o /dev/null http://127.0.0.1:3003/; then echo "npinv is up"; exit 0; fi
    sleep 2
  done
  echo "npinv did not come up; last log lines:" >&2
  docker logs --tail 30 npinv >&2
  exit 1
'
```

Then make it executable:

```bash
chmod +x deploy/deploy.sh
```

- [ ] **Step 4: Create the backup script and its schedule**

Create `deploy/npinv-backup`:

```sh
#!/bin/sh
# Nightly snapshot of the NPInv database.
# Installed as /usr/local/sbin/npinv-backup and run from /etc/cron.d/npinv-backup.
set -eu

DIR=/srv/npinv
STAMP=$(date +%F)

if [ "$(docker inspect -f '{{.State.Running}}' npinv 2>/dev/null)" = "true" ]; then
  # The host has no sqlite3, so the running app takes the snapshot. VACUUM INTO
  # writes a consistent copy even while the database is in use.
  docker exec -e SNAPSHOT="/app/backups/npinv-$STAMP.db" npinv node -e '
    const { rmSync } = require("node:fs");
    const { DatabaseSync } = require("node:sqlite");
    const target = process.env.SNAPSHOT;
    rmSync(target, { force: true });
    const db = new DatabaseSync(process.env.DATABASE_PATH);
    db.exec("VACUUM INTO \x27" + target.replaceAll("\x27", "\x27\x27") + "\x27");
    db.close();
  '
else
  # Nothing is writing, so the database files can be copied as they are.
  if [ ! -f "$DIR/data/npinv.db" ]; then
    echo "no database at $DIR/data/npinv.db"
    exit 1
  fi
  tar -czf "$DIR/backups/npinv-$STAMP.tar.gz" -C "$DIR/data" .
fi

find "$DIR/backups" -name 'npinv-*' -type f -mtime +14 -delete
echo "snapshot written for $STAMP"
```

Create `deploy/npinv-backup.cron`:

```
# Nightly NPInv database backup at 03:20, output goes to the journal (journalctl -t npinv-backup)
20 3 * * * root /usr/local/sbin/npinv-backup 2>&1 | logger -t npinv-backup
```

Then make the script executable:

```bash
chmod +x deploy/npinv-backup
```
